# Библиотека матриц на C

Учебный проект по реализации библиотеки для работы с матрицами на языке C.

## Что реализовано

- арифметические и преобразующие операции над матрицами
- модульное тестирование с использованием Check
- проверка покрытия кода тестами с gcov
- проверка корректности работы с памятью с помощью Valgrind.

## Сборка и тестирование

- статическая библиотека:
```bash
make matrix.a
```
- тесты:
```bash
make test
```

- gcov отчет:
```bash
make gcov_report
xdg-open coverage.html
```

- проверка на leaks
```bash
make valgrind
```

## Стек

- C, Make, Check (check.h), gcov, valgrind
